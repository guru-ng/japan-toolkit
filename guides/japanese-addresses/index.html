How to Read a Japanese Address

Japanese addresses work from the largest area down to the smallest — once you know the layers, even a long address becomes easy to parse.

The postal code

Every Japanese address starts with a 7-digit postal code, written after the postal mark 〒 in the form 〒123-4567. The first three digits identify a region; the last four narrow it down to a town or district level. A postal code usually maps to one specific town area, which is why auto-filling an address from the code works so well in Japan — try it with the Postal Code Lookup.

Largest to smallest

After the postal code, a Japanese address is written in the opposite order to Western addresses: it starts with the prefecture and zooms in step by step.

There are four kinds of prefecture, all at the same level: one to (都, Tokyo), one dō (道, Hokkaido), two fu (府, Osaka and Kyoto), and 43 ken (県, everywhere else). Municipalities are shi (市, city), ku (区, ward — used inside Tokyo and other large cities), chō/machi (町, town), and son/mura (村, village).

Chōme, banchi, gō

The numeric part is what newcomers find strangest: most Japanese streets have no names. Instead, a town is divided into numbered districts:

  • Chōme (丁目) — a district of a few blocks within the town area.
  • Banchi (番地 / 番) — a block (or land parcel) within the chōme.
  • Gō (号) — the individual building on that block.

In everyday writing the three numbers are simply joined with hyphens: 恵比寿1丁目2番3号 becomes 恵比寿1-2-3. Both forms mean exactly the same address, and you can write either on forms and parcels.

A full example, decoded

〒150-0013 東京都渋谷区恵比寿1-2-3 サクラマンション402号室

  • 〒150-0013 — postal code for the Ebisu area
  • 東京都 — Tokyo Metropolis (prefecture level)
  • 渋谷区 — Shibuya Ward (municipality)
  • 恵比寿1-2-3 — Ebisu, chōme 1, block 2, building 3
  • サクラマンション402号室 — Sakura Mansion, room 402

Writing it in English

When romanizing for international mail or forms, the convention is to reverse the order so it reads smallest-to-largest, Western style:

Sakura Mansion #402, 1-2-3 Ebisu, Shibuya-ku, Tokyo 150-0013, JAPAN

Japan Post delivers mail addressed in either order and either script — what matters most is a correct postal code and the chōme-banchi-gō numbers.
